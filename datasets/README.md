# Datasets

The repository includes the small, project-authored [Objective A v2 synthetic control corpus](task006-objective-a-v2/manifest.json) for reproducible software evaluation. It contains 48 synthetic arithmetic and ordering tasks; it is not cybersecurity data, model-quality evidence, or a secret test set. The independent split, similarity, answer, and tokenizer audit is recorded in [the dataset report](../docs/reports/TASK-006-D1-OBJECTIVE-A-V2-DATASET.md).

No external datasets are included or downloaded. Follow [the dataset governance policy](../docs/DATASET_POLICY.md) before sourcing or processing data. Large or restricted datasets must not be committed to Git.
