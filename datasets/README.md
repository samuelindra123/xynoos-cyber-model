# Datasets

The repository includes two small, project-authored Objective A synthetic control corpora for reproducible software evaluation: [v2](task006-objective-a-v2/manifest.json) and [v3](task006-objective-a-v3/manifest.json). V3 reserves semantic input groups and prompt templates by split to reduce measured leakage. Both corpora are public, narrow synthetic tasks; neither is cybersecurity data, model-quality evidence, or a secret test set. See the [v2 report](../docs/reports/TASK-006-D1-OBJECTIVE-A-V2-DATASET.md) and [v3 report](../docs/reports/TASK-006-D1-OBJECTIVE-A-V3-DATASET.md) for their audits, baselines, and limits.

No external datasets are included or downloaded. Follow [the dataset governance policy](../docs/DATASET_POLICY.md) before sourcing or processing data. Large or restricted datasets must not be committed to Git.
