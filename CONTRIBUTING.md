# Contributing

XYNOOS Cyber-Model is early-stage research. Contributions should improve reproducibility, correctness, safety, or clarity and should avoid claims unsupported by implementation or evaluation.

## Before contributing

- Open an issue for substantial design changes or research proposals.
- Keep changes focused and explain the evidence or motivation.
- Do not include credentials, personal data, restricted datasets, model weights, or machine-specific reports.
- Keep local validation lightweight. Large workloads belong in bounded, approved research workflows.

## Pull requests

Describe the change, its scope, validation performed, resource requirements, and any limitations. For research work, include methods, data provenance, configuration, and reproducibility considerations. Do not claim checks passed unless they were run and passed.

By submitting a contribution, you agree that it is provided under the repository's Apache-2.0 license unless a different written agreement applies.
