## Hand-derived attention oracle

Use one batch, one head, head width 2, two valid tokens. Let `q0=(1,0)`, `q1=(0,1)`, `k0=(1,0)`, `k1=(0,1)`, `v0=(2,0)`, `v1=(0,4)`. Scale is `1/sqrt(2)`. Causal token 0 has logits `[1/sqrt2]`, probability `[1]`, output `(2,0)`. Token 1 sees logits `[0,1/sqrt2]`; stable probability `[1/(1+exp(1/sqrt2)), exp(1/sqrt2)/(1+exp(1/sqrt2))]`; output `(2*p0,4*p1)`. Changing token 1 Q/K/V must not change token 0 output. A wrong no-scale variant changes token 1's p values, and a wrong mask changes token 0, so the expected values detect both. Backward uses `dP_s=p_s*(dA dot v_s - sum_j p_j(dA dot v_j))`, then Q/K derivatives scaled by `1/sqrt2`.

## Loss and batch semantics

Targets have `[B,T]`; logits `[B,T,V]`. First validate all IDs, shapes, masks and that every active target is in `[0,V)`. A position is supervised only when `loss_mask && valid_input && valid_target`; PAD targets are never supervised and padded target positions require false loss mask. Count M active positions. If M=0, return typed `NoSupervisedTargets` before tape recording. Per active position: `m=max_v z_v`, `lse=m+ln(sum_v exp(z_v-m))`, `loss=lse-z_y`. Scalar is sum of active losses divided by M, accumulated in f64. Logit gradient is `(softmax(z)_v - 1[v=y])/M` on active positions and exact zero elsewhere. Invalid targets error even if masked, to avoid silently accepting corrupted batches. Extreme finite logits are supported if stable lse remains finite; any final nonfinite value is error. Perplexity is `exp(mean_cross_entropy)` on a named held-out split, only while exponentiation is representable; it is a metric, not a standalone intelligence claim.

## Invariance, isolation and failure tests

- Prefix invariance and future mutation: logits at valid positions `0..k` match when only input IDs after k change; no future token can influence earlier output.
- Padding invariance: valid logits/loss/gradients are equal with or without a PAD suffix under identical valid tokens. Padded queries output exact zero. A sample's keys/queries cannot affect another batch element.
- Batch isolation and shapes: compare batched vs separately evaluated samples; exact `[B,T,V]` and `[B,T]` contracts.
- IDs/vocabulary: reject exact V mismatch and each out-of-range input/target; recognize PAD=258 and DOC_SEP=259 from tokenizer contract.
- Repeated ID scatter-add; tied E gradients equal independent sum of lookup+output paths; deterministic init seed repeat.
- Stable logits `[10000,9999,-10000]`; all-masked invalid query returns zero; all-zero supervision errors; invalid/all-masked keys cannot create NaN.
- Resource exhaustion at tensor, aggregate, nodes, ops, work, arithmetic-overflow and allocation failure seams; verify no parameters, revision, gradients or published outputs change and charges release.
- Debug/release reference results satisfy exact deterministic fixture outputs/tolerances; no external ML runtime is imported.
