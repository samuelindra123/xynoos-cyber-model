Operand ranges are separated by split, and the task-index audit finds no repeated input combination across train, validation, and test. A separate implementation recomputes every task answer, verifies that the answer occurs once after its inputs, and checks the answer end against byte spans expanded from the full-sequence BPE tokens. All 48 answer ends align to an actual token boundary by target position 31 or earlier. However, **8 of 48 answer starts fall inside a BPE token** because the preceding delimiter and `odd` are merged. The standard manifest evaluator reports whole-sequence loss; the follow-up test adds answer-bearing loss masks, but those eight rows include prompt bytes and the result is not strict answer-only loss or accuracy. BPE fitting uses all 24 train rows and no held-out row; a separate standard-library implementation reproduces the exact tokenizer artifact.

## Leakage and evaluation limits

The audit finds no normalized exact cross-split duplicate. It does find **23 cross-split pairs above the fixed 0.82 character-trigram Jaccard threshold**, with a maximum of 0.930233. Independent task-index attribution shows all 23 are pairs from the same task family and the same prompt template; there are zero high-similarity cross-family or cross-template pairs. The score therefore identifies repeated prompt form, not duplicate operands or answers. This reuse is expected for a narrow synthetic function control, but means the data does not measure transfer across language forms. The test split is public and visible in the repository, so it is not a secret holdout. The task-index check finds no exact held-out operand-combination overlap, but cannot establish broad compositional generalization.

This is Objective A only: a small deterministic software control over three authored arithmetic tasks. It does not measure cybersecurity knowledge, Objective B technical-corpus learning, or general reasoning. Twelve examples per task family in validation and test are descriptive, not powered estimates. A separate human data-quality review remains required before admitting this corpus to an authorized experiment.
