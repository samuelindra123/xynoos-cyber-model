## Leakage and evaluation limits

The audit finds no normalized exact cross-split duplicate. It does find **23 cross-split pairs above the fixed 0.82 character-trigram Jaccard threshold**, with a maximum of 0.930233. The repeated templates make this expected and still material: these 48 records do not provide independent language coverage. The test split is public and visible in the repository, so it is not a secret holdout. The task-index check catches exact operand-combination overlap, but it cannot establish broad compositional generalization.

This is Objective A only: a small deterministic software control over three authored arithmetic tasks. It does not measure cybersecurity knowledge, Objective B technical-corpus learning, or general reasoning. Twelve examples per task family in validation and test are descriptive, not powered estimates. A separate human data-quality review remains required before admitting this corpus to an authorized experiment.

## Native runtime evidence

The native data integration test opens the manifest, fits and verifies the tokenizer from train only, checks the saved fit record and artifact, and streams all three splits deterministically. It verifies 24/12/12 complete batches of 32 supervised targets and matching repeatable order identities.

An unchanged-weight manifest-backed baseline is being run as a software evaluation control. Its exact source revision, model-state identity, per-split losses, supervised counts, complete-coverage flags, and locked-test access record will be added after the clean-revision run. This evaluation does not dispatch or constitute training.
