# Security Policy

## Scope

This policy covers vulnerabilities in project code, workflows, documentation, and research infrastructure. The project is early-stage and does not currently provide a trained model or production service.

## Reporting

Please report suspected vulnerabilities privately through GitHub's security advisory reporting for this repository when available. Include affected revisions, impact, and a safe reproduction. Avoid public disclosure before maintainers can assess and coordinate a response. Do not include real secrets, private data, or exploit activity against systems without authorization.

## Research boundaries

Cybersecurity work should support defense, education, secure engineering, and authorized testing. Use isolated environments and follow responsible disclosure practices. This repository does not authorize testing third-party systems.
