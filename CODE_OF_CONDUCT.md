# Code of Conduct

## Our standard

Participants should help maintain a respectful, evidence-oriented environment. Be considerate, assume good faith, give actionable technical feedback, and welcome people with different backgrounds and experience levels.

Harassment, discrimination, intimidation, doxxing, personal attacks, and knowingly harmful disruption are not acceptable.

## Scope and enforcement

This applies to project spaces and public interactions where someone represents the project. Report concerns privately to the repository maintainers. Maintainers will review reports, protect reporter privacy where practical, and take proportionate action, including content removal or participation restrictions.

This code is adapted from the Contributor Covenant principles; it is project guidance and is not a separate license for contributions.
